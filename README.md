# 👑 Batabitoo Cloud Mail Center (Firebase & PWA Powered)

نظام إدارة وصناديق البريد الإلكتروني السحابي المزدوج لنطاق `batabitoo.com` والبريد السريع متعدد النطاقات، مدعوم بقاعدة بيانات **Google Cloud Firestore** ومتوافق كلياً مع الهواتف الذكية بنظام البطاقات المدمجة (Compact Cards) وتطبيق ويب تقدمي (PWA).

## 📱 ميزات تطبيق الويب المتكامل (PWA):
1. **تثبيت التطبيق على الجوال بنقرة واحدة:**
   - متوافق مع Android و iOS (iPhone) عبر خيار "إضافة إلى الشاشة الرئيسية" (Add to Home Screen).
   - يعمل كتطبيق مستقل (Standalone) مع أيقونة ملكية خاصة بدون شريط المتصفح.
2. **فصل كامل بين الحسابات الرسمية والوهمية:**
   - **👑 الإيميلات الرسمية (`@batabitoo.com`):** مخصصة للمنصات الكبرى وتفعيل أمازون، ذات موثوقية عالية مع شارة ذهبية وتصنيف مستقل.
   - **⚡ الإيميلات الوهمية / السريعة:** أكثر من 20 نطاق عشوائي لإنشاء آلاف الصناديق الفورية.
3. **قاعدة بيانات سحابية لحظية (Google Cloud Firestore):**
   - المشروع السحابي: `batabitoo-mail-2026`
   - المزامنة الفورية لكافة الصناديق والرسائل وسجلات نيفيا مع دعم العمل المحلي التلقائي دون انقطاع (Offline Fallback).
4. **معالجة حقيقية للرسائل الواردة (وداعاً للأكواد المشفرة):**
   - فك تشفير شامل لرسائل MIME المعقدة (Amazon, Google, etc.).
   - عرض الرسالة بتنسيقها الحقيقي (Authentic HTML) أو كنص عربي نظيف بدون أي أكواد زائدة.
   - استخراج فوري لكود التحقق (OTP) وزر نسخ بنقرة واحدة مباشرة من البطاقة.
5. **تصميم متحرك للجوال:**
   - مشهد بريد ثلاثي الأبعاد باستخدام Three.js، مع رسم بديل عند تعطيل الحركة أو تعذّر WebGL.
   - إيقاف الرسم خارج الشاشة وفي الخلفية، ودعم إعداد تقليل الحركة.
   - تنقّل سفلي، بحث، وحمْل الصناديق على دفعات من 40 صندوقًا.
   - في Android: مؤثرات منظور وحركة أصلية بـ Compose، وتمرير للنماذج والرسائل الطويلة.

## 📱 تطبيق Android الأصلي

يوجد تطبيق Android كامل مبني بـ **Kotlin + Jetpack Compose** داخل مجلد `android/`. التطبيق ليس WebView؛ كل القوائم والتنقل والبحث والنوافذ أصلية، ويستخدم WebView آمنًا فقط لمعاينة محتوى رسالة HTML.

### الميزات

- عرض الصناديق الرسمية والسريعة والبحث فيها وتحديد الصندوق النشط وحذفه.
- إنشاء بريد رسمي `@batabitoo.com` أو بريد سريع متعدد النطاقات.
- عرض الوارد والرسائل الرسمية والسريعة مع نسخ رمز OTP مباشرة.
- معاينة الرسالة الأصلية أو النص النظيف.
- سجل تسجيلات نيفيا والبحث بالاسم والجوال والفاتورة.
- تحديث تلقائي كل 8 ثوانٍ، تخزين مؤقت للعمل عند انقطاع الاتصال، وتغيير عنوان الخادم من الإعدادات.
- **نظام التحديث المباشر من داخل التطبيق (In-App Direct Update):** فحص الإصدار التلقائي عبر قاعدة البيانات مع زر فوري وبانر للتحميل والتثبيت المباشر دون الحاجة لمتاجر التطبيقات. راجع دليل الوكلاء: [APP_UPDATE_GUIDE.md](APP_UPDATE_GUIDE.md).

### البناء

```powershell
cd android
.\gradlew.bat testDebugUnitTest assembleRelease
```

ملف التثبيت الجاهز في جذر المشروع: `Batabitoo-Mail-Center-1.1.0.apk`.

### التحقق من التصميم

`node scripts/verify-design.cjs` يفحص نسخة الخادم المحلي على شاشات 320 و390 و1440 بكسل، تشغيل WebGL، تقليل الحركة، البحث، الدفعات، والنوافذ. يستخدم Chrome المثبّت ويمنع طلبات تعديل البيانات أثناء الفحص. يمكن تحديد `DESIGN_URL` لفحص الرابط المنشور.
